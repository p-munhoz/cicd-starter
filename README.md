# cicd-starter

Companion repository for the series **CI/CD in Practice: GitHub Actions**, published at [blog.pmunhoz.com](https://blog.pmunhoz.com).

Each article has its own branch. Check out the branch for the article you are reading and follow along from there.

| Branch | Article |
|--------|---------|
| `article-02` | [Your First GitHub Actions Workflow](/blog/github-actions/github-actions-first-workflow/) |
| `article-03` | Build and Test Automation *(coming soon)* |
| `article-04` | Secrets, Environments, and Configuration *(coming soon)* |
| `article-05` | Reusable Workflows and Composite Actions *(coming soon)* |
| `article-06` | Matrix Builds and Parallelism *(coming soon)* |

## How to use this repo

```bash
git clone https://github.com/pierremunhoz/cicd-starter.git
cd cicd-starter
git checkout article-02
```

Then follow the exercise in the article.
